# Roadmap V3

Status: replaces the broad implementation sequence during the reset research

1. **Gate M:** validate oracle semantics, confidentiality, freezes, receipts,
   costs, scheduling, and deterministic failures on four to six task bundles.
2. **Gate H:** on frozen representative and high-gap slices, estimate causal
   headroom and the minimum sufficient correct-information intervention.
3. **Gate A:** only for a category that passes Gate H, test the smallest
   practical approximation against deterministic, equal-budget, oracle, and
   Sol controls.
4. **Verdict:** choose deterministic specialist, one learned specialist,
   observation capability, reliability-only, explicit hybrid, pivot, or stop.

No LunaGuide, training pipeline, agent search, arbitrary generated tool, broad
context compiler, or Plugin UI is authorized by this roadmap. The next gate is
earned by the preceding measurement, not by code completeness.
