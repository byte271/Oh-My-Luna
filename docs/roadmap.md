# Roadmap

## Gate C: evaluation mechanics

Complete typed fixtures, runner/adapters, isolated workspaces, trace and
artifact capture, scoring, cost accounting, reproducibility metadata, and tests.

Exit: deterministic fixture run produces a valid receipt; all tests pass.

## Gate D: one vertical mechanism

Implement Task IR, source-addressed context capsule, one high-level runtime
probe, scoped patch handoff, evidence invalidation, and claim receipt.

Exit: end-to-end operation on one development task without generated source or
multiple agents.

## Gate E: controlled comparison

Run native Luna, fixed skill, full V0, and Sol on development and held-out tasks.
Publish all traces and failures that can be redistributed.

Exit: kill criteria applied without changing thresholds after results.

## Gate F: decision

Choose exactly one:

- continue with context + evidence + capability composition;
- narrow to fixed high-level probes;
- focus only on context/evidence;
- enable a limited generated-instrument research arm;
- pivot or stop.

## Later, only if earned

- Luna snapshot profiler and automatic regression alerts;
- TypeScript/Python AST/LSP capability packs;
- reviewed plugin packaging and local MCP server;
- Windows/macOS/Linux sandbox backend conformance suite;
- offline prompt/workflow optimization;
- explicit hybrid escalation policy.
