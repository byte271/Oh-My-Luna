# Architecture alternatives

## Selected for the first proof

Context compilation plus a fixed evidence flow, augmented by one validated
high-level runtime observation capability. This is the smallest configuration
supported by Aider/SWE-agent interface evidence, SkillsBench's curated-skill
result, and Debug2Fix's ablation.

## Deferred

- Capability retrieval and declarative composition: include narrowly after the
  fixed flow works.
- One independent branch: evaluate only for competing hypotheses with an
  objective merger.
- Offline Sol distillation: test as a declared development-time arm after a
  stable task distribution exists.
- DSPy/Agent Lightning optimization: integrate only when stored traces and a
  reliable metric justify automated optimization.
- Workflow search: development-time only after a safe evaluator, enough tasks,
  and a fixed-template baseline exist.

## Rejected as V0 core

- JIT arbitrary tool generation: weak self-generation evidence and unacceptable
  verification/security burden.
- Permanent multi-agent swarm: cost and synchronization without Luna-specific
  marginal-value evidence.
- Large role/prompt catalog: confounds causal evaluation and consumes context.
- LangGraph or a distributed service mesh: more runtime than the first vertical
  proof requires.
- Universal memory or research assistant scope: no connection to the first
  objectively verifiable failure mode.

## Reversal rule

Any rejection can be reversed only by a pre-registered paired experiment on
held-out repository tasks showing an attributable gain after cost, latency,
security failures, and simple-task regressions are included.
