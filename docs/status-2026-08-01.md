# Gate status — 2026-08-01 (America/New_York)

## Verdict

**Inference:** Oh-My-Luna is technically credible only as a narrow experimental thesis: tested high-level capabilities plus context selection and evidence gating may close part of Luna's harder-task gap. The broader “self-optimizing cognitive runtime” and unrestricted generated-tool thesis are not supported.

No release claim is justified. Gate D and Gate E remain unstarted.

## Completed

- **Verified repository fact:** all Gate A and Gate B files named in the project brief exist; `research/sources.json` contains 41 source records.
- **Verified repository fact:** Gate C implements a strict task fixture, external model-adapter interface, filesystem-copy environment provider, hash-linked trace, content-addressed artifact store, deterministic verifier interface, cost accounting, receipt schema, CLI, and tests.
- **Measured local result:** `npm run typecheck` passed with TypeScript 5.9.3 strict settings.
- **Measured local result:** `npm test` passed 11/11 tests on Node 24.14.0, Linux 6.12.13 x86_64. The tests cover canonical hashing, costs, path and symlink rejection, schema rejection, trace tamper detection, successful orchestration, failed-verifier gating, and sandbox refusal.
- **Measured local result:** `npm audit --omit=dev` reported 0 vulnerabilities after upgrading AJV from 8.17.1 to 8.20.0. The earlier pin carried GHSA-2g4f-4pwh-qvx6.
- **Measured local result:** the deterministic smoke run emitted a schema-valid `verified` receipt in 68 ms. Its adapter was `test-double/not-a-model`, reasoning effort `none`, tokens 0, and cost $0. This is not a model evaluation.

## Not completed

- **Verified environment fact:** `OPENAI_API_KEY` was absent; a Codex executable, Docker, and Podman were unavailable.
- **Consequence:** no native Luna, fixed-Skill, Oh-My-Luna, Oh My Codex, or Sol run was performed. There are no private success-rate, quality, latency, or cost measurements.
- **Consequence:** the included isolation backend cannot safely run untrusted repository tests. It refuses fixtures that declare `requires_security_sandbox: true`.
- **Consequence:** no GPT-5.6 Luna profile has been measured, no vertical runtime has been built, and no release decision under Gate F can be made.

## External observations, not project measurements

- **Source-backed observation:** the official model pages list Luna and Sol token prices at a 25:1 ratio for input, cached input, and output as retrieved 2026-08-01.
- **Source-backed observation:** the Vals SWE-bench Verified page updated 2026-07-31 reports 93.0% for Luna and 96.2% for Sol under its minimal-agent setup; on its 42 tasks labeled one-to-four hours, it reports 86% and 98%, respectively. Reproduction settings and traces available on that page are not sufficient for a causal Oh-My-Luna claim.
- **Source-backed observation:** SkillsBench reports curated skills helped on average but self-generated skills did not, and software-engineering gain was much smaller than its overall gain.
- **Source-backed observation:** Debug2Fix reports high-level debugger assistance helped several coding-agent configurations while direct low-level debugger tools could be flat or harmful.

## Next decision

**Design decision:** continue only to one sandboxed vertical experiment. Do not build a general runtime, plugin marketplace, generated-code foundry, profiler service, or adaptive graph optimizer first.

**Reversal condition:** if the composition-first treatment fails the preregistered high-gap success threshold or its gain disappears after retry normalization and held-out evaluation, narrow the project to context-and-evidence tooling or stop.
