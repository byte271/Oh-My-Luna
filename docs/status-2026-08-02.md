## Protocol decision

The symmetric six-level pre-edit ladder did not survive. The primary design is
L0 native through L5 behavioral plan, cumulatively. Verification-gap assistance
is a separate post-first-patch rescue because its timing differs. Selected
independent arms are exploratory only. If reviewers cannot distinguish raw
observation from diagnosis, L3 and L4 must collapse into one decisive-
diagnostic-fact level.

Gate H measures the value of correct information. Gate A later tests whether a
practical component can approximate it. A positive oracle result does not
authorize LunaGuide, another learned component, or any broad runtime.
